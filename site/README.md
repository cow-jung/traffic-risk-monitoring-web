# 위기탈출 넘버 포 — 홈페이지

## 폴더 구조

```
site/
├── index.html            # 홈 (히어로 + 미리보기 섹션)
├── pages/
│   ├── about.html        # 개요(소개)
│   ├── control.html      # 관제 화면
│   ├── notice.html       # 공지사항
│   ├── board.html        # 게시판
│   └── login.html        # 로그인
├── css/
│   └── style.css         # 전체 스타일 (비어 있음)
├── js/
│   └── main.js           # 전체 스크립트 (비어 있음)
└── assets/
    └── images/           # 이미지 리소스
```

## 참고

- 모든 html 파일은 태그 구조만 잡아 둔 뼈대이며, 텍스트/스타일/스크립트 내용은 비어 있습니다.
- css/style.css, js/main.js는 각 페이지에서 상대경로로 이미 연결되어 있습니다.
