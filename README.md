# traffic-risk-monitoring-web

프로젝트 파일을 용도별로 구분합니다.

## 구조

- `mini-project/` — 현재 미니프로젝트 웹 대시보드 및 Flask 실행 파일
- `final-project/` — 파이널 프로젝트 전용 영역
- `RaspberryPI/` — 라즈베리파이 카메라/ROI 관련 코드

## 미니프로젝트 실행

```powershell
cd mini-project
py app.py
```

대시보드: `http://192.168.2.76:5000/control`

## 정리 대기

루트의 기존 `index.html`, `pages/`, `css/`, `js/`, `assets/`는 이전 웹 버전으로 보이지만 삭제 전 사용자 확인을 위해 현재 유지합니다.
